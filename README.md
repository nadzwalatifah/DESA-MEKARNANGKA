# Profil Desa Mekarnangka

Desa Mekarnangka adalah salah satu wilayah yang terletak di Kecamatan Cikidang, Kabupaten Sukabumi, Jawa Barat. Website resmi ini dikembangkan sebagai pusat informasi digital untuk mendukung transparansi pemerintahan, publikasi kegiatan warga, serta mengenalkan berbagai potensi lokal yang ada di desa.
